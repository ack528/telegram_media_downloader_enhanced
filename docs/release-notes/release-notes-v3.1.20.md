## 下载范围筛选

- 桌面端「下载 → 体积与分辨率」可设置文件体积上下限和视频分辨率上下限，保存时校验范围。
- 引擎在传输前检查 Telegram 媒体元数据，不符合条件时跳过。体积按 MiB，视频分辨率按短边像素计算，范围包含边界；0 或省略表示不限。
- 体积限制适用于所有媒体；分辨率限制适用于 Telegram 视频及视频消息。以文件发送的视频不适用分辨率筛选。开启限制后，缺少对应元数据的媒体会被跳过。
- 默认不限制；原有配置可继续使用。独立引擎可通过 `config.yaml` 的 `download_limits` 配置，详见 README_CN。

## 下载

- `TDL-Desktop-v3.1.20-portable-x64.zip`：Windows 桌面绿色版，包含桌面程序、引擎和绿色模式标记。需要 Windows 10/11 与 WebView2。
- `tdl-v3.1.20.exe`：Windows 独立下载引擎。

升级前请退出旧程序，备份配置、会话和数据；解压后将程序文件复制到原目录，保留原有配置与会话。
